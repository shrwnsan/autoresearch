## 2. Background

### What is TinyStories?

TinyStories is a dataset of ~2.1M short stories generated by GPT-3.5 and GPT-4, designed for training small language models. Each story:
- Uses simple vocabulary
- Has clear narrative structure
- Is 100-500 words long
- Contains moral lessons or simple plots

**Example Story:**
```
Once upon a time, there was a little bunny named Fluffy. Fluffy loved to hop
through the meadow and eat carrots. One day, she found a magical carrot that
glowed in the dark. Fluffy was very happy and shared it with all her friends.
The end.
```

### Why It's Perfect for Learning

| Aspect | TinyStories | General Web Text |
|--------|-------------|------------------|
| **Vocabulary** | ~5K words | ~100K+ words |
| **Sentence structure** | Simple | Complex |
| **Topic range** | Narrow (stories) | Everything |
| **Model size needed** | 10-50M params | 100M+ params |
| **Training time** | Minutes | Hours/Days |
| **Evaluation** | Easy (read stories) | Hard (diverse outputs) |

# TinyStories dataset
TINYSTORIES_URL = "https://huggingface.co/datasets/karpathy/tinystories-gpt4-clean/resolve/main"
TINYSTORIES_TRAIN = "tinystories_gpt4_train.parquet"
TINYSTORIES_VAL = "tinystories_gpt4_val.parquet"

def download_tinystories():
    """Download TinyStories dataset from HuggingFace."""
    import requests

    os.makedirs(DATA_DIR, exist_ok=True)

    for filename in [TINYSTORIES_TRAIN, TINYSTORIES_VAL]:
        filepath = os.path.join(DATA_DIR, filename)
        if os.path.exists(filepath):
            print(f"  {filename} already exists, skipping")
            continue

        url = f"{TINYSTORIES_URL}/{filename}"
        print(f"  Downloading {filename}...")

        response = requests.get(url, stream=True, timeout=60)
        response.raise_for_status()

        with open(filepath, "wb") as f:
            for chunk in response.iter_content(chunk_size=1024 * 1024):
                f.write(chunk)

    print("TinyStories download complete!")

# Replace the main data preparation with:

### Qualitative Evaluation

#### Story Quality Rubric

| Score | Description | Example |
|-------|-------------|---------|
| **1 (Random)** | No structure, random words | "the cat walked blue happily yesterday carrot" |
| **2 (Fragments)** | Some phrases, no coherence | "Once upon a time. The dog. Happy ending." |
| **3 (Simple)** | Basic story structure | "A cat found a ball. The cat played. The end." |
| **4 (Coherent)** | Clear narrative, makes sense | "A cat named Whiskers found a magic ball. She played with it all day. Her friends joined in. They lived happily." |
| **5 (Engaging)** | Good story, creative elements | "Whiskers the curious cat discovered a glowing ball in the old oak tree. When she touched it, sparkles filled the air. Her kitten friends gathered around in amazement..." |

#### Evaluation Script

```python
# generate.py - Story generation and evaluation

import torch
from train import GPT, GPTConfig, Tokenizer

def generate_story(model, tokenizer, prompt, max_tokens=100, temperature=0.8):
    """Generate a story continuation."""
    model.eval()
    tokens = tokenizer.encode(prompt)
    tokens = torch.tensor([tokens], device=model.device)

    with torch.no_grad():
        for _ in range(max_tokens):
            logits = model(tokens)
            next_token = sample(logits[0, -1], temperature)
            tokens = torch.cat([tokens, next_token.unsqueeze(0).unsqueeze(0)], dim=1)

            if next_token == tokenizer.eos_token_id:
                break

    return tokenizer.decode(tokens[0].tolist())

def sample(logits, temperature):
    """Sample from logits with temperature."""
    probs = torch.softmax(logits / temperature, dim=-1)
    return torch.multinomial(probs, 1)

# Test prompts
test_prompts = [
    "Once upon a time, there was a little",
    "The brave little mouse decided to",
    "In a magical forest, a unicorn",
    "A young boy named Tim loved to",
    "The friendly dragon wanted to make friends with",
]

def evaluate_model(model_path):
    """Generate sample stories and print for evaluation."""
    tokenizer = Tokenizer.from_directory()
    model = load_model(model_path)

    print("=" * 60)
    print("STORY GENERATION EVALUATION")
    print("=" * 60)

    for prompt in test_prompts:
        story = generate_story(model, tokenizer, prompt, max_tokens=100)
        print(f"\nPrompt: {prompt}")
        print(f"Story: {story}")
        print("-" * 60)
```
